📅 落地流程建议

以下为建议顺序，具体可灵活调整，不用严格对应每一天

第1天 · 到达日
🛬 出机场 → 🛒 手机卡 → 🚇 Opal卡 → 🏠 入住

① 买 SIM 卡
到达大厅有 Optus 门店或去 Coles 买 $35 月卡，护照即可。✅ 小红书992赞

② 买 Opal 交通卡
机场便利店买，充 $20-40，坐火车去 Macquarie Park / Epping。✅ 小红书253赞

③ 放行李到 SVNR（122 Culloden Rd, Marsfield）
次日正式 check-in，今晚先落脚。

第2天
🏦 银行卡 → 📄 TFN → 🛍️ 采购日用品

优先办：银行卡
Commonwealth Bank @ Macquarie Centre 2楼
带：护照 + 签证信 + SVNR地址 + 手机号✅ 小红书验证

线上申请：TFN
ato.gov.au — 10分钟免费，用SVNR地址❓ 收到需约2-4周

顺便去 Coles/Woolies 买床品、日用品

第3天
🎓 MQ 校内：学生证 → USI → OSHC → iLearn

Student Connect 领学生证
提前在 eStudent 上传照片（现场拍很丑）✅ 小红书共识

在线搞定：USI号（usi.gov.au）→ OSHC激活 → iLearn模块

📱 顺便换 Coles Mobile 年卡（$155-195/年 ≈ $13/月）✅ 小红书992赞

第4-6天
🧘 熟悉环境 + 扫尾

熟悉 Macquarie Centre、Eastwood（最近的华人区）、Chatswood（北区华人中心）
确认 iLearn 和 eStudent 选课
收银行卡邮件通知、等 TFN 寄到
去 Kmart / Target 补生活用品

第7天+
🎉 Kickstart Week（迎新周）

迎新周开始！日程指南 👉 mq-kickstart-guide

📱 手机卡详解

方案价格流量适合来源
Optus 月卡 $35/28天 40GB 落地过渡，拿护照就能买 ✅
Coles Mobile 年卡 $155/年（≈$13/月） **140GB/年**（一年总量，非每月） 长期省钱方案，365天有效 ✅
Vodafone $20-30/月 30-60GB 最便宜但信号差 ✅
Telstra $35-50/月 25-50GB 信号最好最贵 ✅

✅ 推荐策略：
落地买 Optus $35 月卡过渡 → 安顿好后换 Coles Mobile 年卡（$155/年，140GB一年总量，≈$13/月，Optus网络信号一样好）

🏦 银行卡详解

银行学生月费优势来源
Commonwealth❓ 待确认ATM最多，Macquarie Centre有分行✅ 第一站选它
中国银行（澳洲）❓ 待确认国内中行→国外中行 转账0手续费✅ 技巧已验证
ANZ / NAB🤖 AI备选🤖 未验证

✅ 小红书推荐的技巧：
国内中国银行 → 澳洲中国银行 → 转到 CommBank
这样房租基本可以做到 0 手续费✅ 小红书253赞
